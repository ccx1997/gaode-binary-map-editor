# 高德地图道路与楼栋编辑器

把配色与示例相近的高德小区地图截图转换为白底、灰色道路中心线和黑边楼栋地图，并在本地网页中继续编辑。

> 当前第一版只保证在 macOS 上可用。地图图片和标注全部在本机处理，不会上传到网络。

## 当前能力

- 自动识别绿色区域，去除文字、图标和原图颜色干扰。
- 自动区分细长道路网络和紧凑楼栋：道路提取中心线后默认加粗为灰度 **127**，楼栋轮廓为 **0**，背景为 **255**。
- 道路中心线默认宽 9 px，可通过 `--road-width` 调整自动生成宽度。
- 点击“加粗道路线”可将全部道路每次加粗 2 px；“道路颜色”滑块可在 0–255 之间实时调整灰度。两项设置均可撤销并随工程保存。
- 用两点补画灰色道路，可调整线宽、移动整段、拖动端点、删除、撤销与重做；道路默认可画任意角度。
- 用矩形画可行区（白色），或用“画矩形”补画黑色空心楼栋轮廓，可移动、修改宽高和线宽。
- 点击封闭白区可预览并填充不规则障碍区；检测到 1–8 px 的疑似边界缺口时，会用橙色圆圈和十字标出修补位置。
- 用“框选道路”高亮框内道路，再用“删除道路”清除；保留楼栋黑边，支持撤销和重新补画。
- 框选已有楼栋作为模板，按矩形框范围原样复制当时的灰度内容，包括楼内修改。
- 粘贴的楼栋可整体移动并调整宽高，楼内标注会随楼栋同步移动、缩放。
- 编辑视图可每次顺时针旋转 90°，不改变原始坐标和导出方向。
- “查看原图”是纯预览模式，会暂时隐藏全部人工标注并阻止误编辑；缩放和平移仍可使用。
- 支持点击起点和终点验证道路连通性，逐像素沿道路规划，默认使用 0 px 障碍安全边距。
- 支持选择、移动、撤销、重做、缩放、平移和裁剪保留框。
- 支持在道路上标注楼栋入口，保存字符串标签，修改标签、拖动入口位置和删除，并支持撤销、重做。
- 导出后网页会自动切换为裁剪结果预览并隐藏黄色裁剪框；刷新或下次自动恢复时仍保持裁剪结果预览。可用“显示完整地图”返回完整编辑范围，或再次选择“裁剪保留框”重新绘制。
- 导出保留黑色、所选道路灰度和白色的 PNG，以及可重新导入的标注 JSON。
- 点击导出时自动保存本地工程；下次用同一张原图启动时自动恢复。
- 全程在本机处理，不上传地图。

## 安装

macOS 终端进入本目录后执行：

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
```

## 使用

```bash
./.venv/bin/python map_converter.py --input "/path/to/小区高德地图.jpeg"
```

脚本会生成初始底图并自动打开本地编辑网页。关闭终端中的脚本即可停止网页服务。

```text
--output-dir outputs  初始底图输出目录
```

## 导出和继续编辑

网页中的“导出 PNG + JSON”会下载：

- `*_map.png`：最终灰度地图（建筑与障碍为 0，道路使用滑块所选值，背景为 255）；设置裁剪框后只导出框内区域。
- `*_annotations.json`：包含原图尺寸、裁剪框、可行区、矩形轮廓（`outlineRects`）、道路删除范围（`roadErases`）、封闭填充障碍区、道路中心线（`roadLines`）、楼栋入口特殊点（`specialPoints`）、楼栋组合及裁剪后坐标；兼容旧工程的矩形障碍区和障碍线。

点击导出时，程序还会在本机的 `outputs` 目录保存 `*_editor_project.json`。以后使用同一张原图、从同一项目目录启动脚本时，网页会自动恢复到上次导出的状态，不需要再次手工导入 JSON。只有点击导出才会更新该本地工程，尚未导出的临时操作不会覆盖上次状态。

“导入标注 JSON”仍可用于换电脑、接收别人提供的工程，或者恢复某个历史版本。JSON 中保留的是原图坐标，因此即使导出时使用了裁剪框，也能正确恢复编辑状态。

Chrome 可能会把一次导出的两个文件识别为“多个文件自动下载”。如果地址栏显示“下载已被阻止”，请允许当前 `127.0.0.1` 本地网页下载多个文件，再重新点击导出。请确认 PNG 和 JSON 都实际出现在下载目录后再关闭网页。

## 发给别人使用

只使用转换和编辑工具时，把本仓库地址发给对方。对方执行：

```bash
git clone <仓库地址>
cd gaode-binary-map-editor
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python map_converter.py --input "/path/to/map.jpeg"
```

只需要查看或处理最终灰度地图时，发送导出的 `*_map.png` 即可。

需要继续编辑已有地图时，必须同时提供：

1. 完全相同的原始地图截图。
2. 对应的 `*_annotations.json`。
3. 本工具的仓库地址。

对方用原始截图启动网页后，点击“导入标注 JSON”即可恢复可行区、障碍区、障碍线、复制区域和裁剪框。原图尺寸必须与 JSON 记录一致。

`*_annotations.json` 是本编辑器的工程文件，不是 ROS/Nav2 地图格式。当前导出的 PNG 没有 `resolution`、`origin` 等实际尺度信息，因此不能单独作为完整的 Nav2 地图直接部署。

## 道路编辑与旧工程

- 点击“画道路中心线”，依次点击两点绘制线段。左侧“新增道路线宽”决定下一段的基础宽度，已绘制线段可在选中项中单独修改。
- “加粗道路线”每次为全部道路增加 2 px（最多累计增加 100 px），包括自动道路、手工道路和复制图块内的道路；楼栋黑边保持不变。
- “道路颜色”滑块范围为 0–255，默认 127，影响预览和 PNG 导出。颜色与累计加粗量保存在 JSON 的 `project.roadStyle` 中，支持撤销、重做、导入和自动恢复。
- 使用“选择编辑”移动道路或拖动端点；道路有独立的水平／垂直吸附开关，默认关闭。
- 点击“框选道路”后拖出矩形，框内的自动道路、手工道路和复制图块中的道路会高亮；点击“删除道路”或按 Delete 清除框内道路。只清除道路像素，不会抹掉楼栋和障碍边界；Esc 取消框选。
- 删除按编辑顺序保存，调整颜色或继续加粗不会恢复已删除区域；之后可用“画道路中心线”重新补画。删除范围也会显示在标注列表中，移除该记录可恢复被它遮去的道路。
- 裁剪、复制图块、PNG 导出、JSON 保存和恢复均保留道路设置。继续编辑自定义道路颜色时，请使用原图和标注 JSON，以保留道路与建筑的类别信息。
- “矩形障碍区”和“画障碍线”入口已移除。旧版 JSON 仍可导入，缺少的新标注类型视为空列表；旧人工障碍线、障碍矩形和复制图块仍保留，可选中后修改或删除。仓库 `communities/*/maps/final/` 仅在人工确认并提交新地图时更新，启动转换不会覆盖其中的文件。
- 自动分离依赖示例配色和形状：细长连通区域视为道路，紧凑区域视为楼栋。与道路粘连或特别狭长的楼栋可能需要人工修正。

## 楼栋入口标签

1. 点击“标注楼栋入口”，再在道路线上点击入口位置；附近 12 px 内会吸附到最近道路像素，距离过远则提示重新选点。自动道路、手绘道路和复制图块内的道路均可标注，道路显示颜色不影响选点。
2. 在出现的“楼栋入口标签”面板输入字符串（如 `3栋1单元入口`），点击“保存入口标签”或按 Enter。地图用紫色圆点和文字显示入口，右侧列表同步显示标签及坐标。空标签不能保存；选点后可按 Esc 或点击“取消选点”。
3. 点击入口圆点或右侧列表，在同一面板修改标签后点击“保存修改”。切换到“选择编辑”可以拖动入口，新位置仍须位于道路附近；拖到远离道路的位置时保留最后有效位置。可删除入口，新增、修改、移动和删除均支持撤销、重做。
4. 点击“导出 PNG + JSON”将入口随工程保存到本机，下次启动自动恢复，也可通过 JSON 导入继续编辑。面板中的保存先写入当前编辑状态，持久保存与其他标注一致，需要点击导出。

入口记录存放在 `project.annotations.specialPoints`，包含 `id`、`type: "buildingEntrance"`、字符串 `label`、原图像素坐标 `x` / `y` 和 `drawOrder`。坐标原点在原图左上角，X 向右、Y 向下。`exported.annotations.specialPoints` 只包含裁剪范围内的点，并减去裁剪偏移；完整工程仍保留范围外的入口。没有 `specialPoints` 的旧工程按空列表恢复。

入口为独立的位置标注：之后移动、删除道路或复制楼栋不会自动移动、删除或复制入口，需要自行检查和调整。入口文字和圆点只显示在编辑网页，不写入灰度 PNG，也不影响道路连通性；原图预览会暂时隐藏它们。

## 矩形与障碍区

- “画矩形”用于补画黑色空心轮廓，内部内容保持原样。默认按底图楼栋的实际黑边设置线宽（当前示例为 5 px），也可通过“新矩形边框线宽”预先指定。已创建的矩形可在选中项中修改位置、宽高和线宽。
- 点击“调整矩形宽度”，再点击一个手绘矩形，即可用 1–100 px 的“边框线宽”滑块实时调节；“与楼栋线宽一致”可一键匹配底图。调节不改变矩形位置、外部尺寸及其他标注，支持撤销、重做和 JSON 保存。旧工程保留已设置的矩形线宽，可选中后调整。
- “点击填充障碍区”用于已经被黑线完全封闭的不规则白色区域。第一次点击显示红色预览，再次点击红色区域才会确认填黑；按 `Esc` 可取消预览。
- 填充前会自动检查 1–8 px 的小缺口。若发现填充会从小缺口泄漏，地图会用橙色圆圈、十字和编号标出疑似位置，左侧同时显示像素坐标。请放大检查并调整现有边界后，再重新点击填充；橙色标记在切换工具后会保留，按 `Esc` 可清除。
- 橙色标记是根据像素连通关系得到的疑似位置。缺口过宽、多个开口连在一起或边界结构过于复杂时，程序可能无法可靠定位；此时会明确提示放大后人工检查，不会直接误填大范围区域。
- 如果填充范围连接地图边缘，或超过整张地图的 35%，程序仍会拒绝填充，避免把道路和地图背景整体填黑。
- 封闭填充会作为 `obstacleFills` 保存到 JSON，可撤销、删除、导入和再次导出；为保证边界准确，填充区不能直接移动，需要调整时删除后重新填充。

## 复制缺失楼栋

1. 点击“框选复制楼栋”。
2. 先完成该楼栋内部的可行区、轮廓和填充修改。
3. 直接拖出复制框；框多大就复制多大，框内所有灰度像素都会保留。
4. 程序不会再替你判断楼栋轮廓，也不会把范围缩小为某个自动识别结果。
5. 提取成功后会自动进入“粘贴楼栋”，移动鼠标预览并单击放置，可连续放置。
6. 切换到“选择编辑”，可移动复制区域，并在左侧调整宽、高；框内内容会整体同步变化。
7. 选中已粘贴楼栋后，也可以使用 `Command+C`、`Command+V` 连同内部布局再次复制粘贴。

复制楼栋采用所见即所得的矩形图块：道路、楼栋和人工标注只要落在框内都会被复制。因此框选范围完全由你决定，程序不会自动排除道路。图块会一并保存到标注 JSON 中，以便下次继续编辑。

“顺时针旋转 90°”只旋转网页中的编辑视图，便于从不同方向操作地图；标注坐标、裁剪坐标和最终导出的 PNG 方向保持不变。

道路线可通过“道路水平/垂直吸附”限制方向，默认关闭。矩形轮廓始终与地图坐标轴对齐，视图旋转不改变标注坐标。

## 全局路线验证

1. 点击“验证全局路线”。
2. 在当前地图上点击起点，再点击终点。
3. 规划器实时合成尚未导出的编辑结果，只在道路上通过 A* 计算路线。白色背景（包括“画可行区”覆盖的区域）、已删除道路和黑色楼栋/矩形边界不可通行；需要连接断路时使用“画道路中心线”补画。
4. 起终点可在 40 px 的实际距离内吸附到最近可通行道路，超出范围会提示重新选择；画面用“起”“终”和箭头显示实际路线方向。
5. 默认障碍安全边距为 0 px，按每个像素验证，保留细道路和细小断口。调大安全边距会避开黑色边界附近的道路像素，过大时可能使窄路无法通行。
6. 路线简化后仍须全程落在道路上，不跨越白色空地、道路断口或黑色边界，不斜穿障碍角。
7. 加粗、删除、补画道路、画矩形、裁剪或撤销编辑后，旧路线自动失效，请重新选择两点。仅调整道路显示颜色时保留验证结果，颜色为 0 或 255 时也不改变道路的通行含义。

“规划成功：两点之间道路连通”只证明本次所选起点到终点的道路连通，不代表整张地图所有区域都已验证。路线、起点和终点仅为临时验图覆盖层，不写入标注 JSON，也不会出现在导出的灰度 PNG 中。地图中没有道路时会提示先画道路，不会将整片白色背景作为替代路线。

## 适用范围

当前针对示例中的浅绿色背景、浅灰色道路和楼栋的高德小区地图截图。自动结果是人工编辑的起点，不应直接当作机器人可部署地图；请在导出前检查道路中心线、楼栋轮廓和被文字遮挡的位置。
